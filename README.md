Minimal but useful Next.js template.

## Features

- basic [Next.js](https://nextjs.org/) setup using [TypeScript](https://www.typescriptlang.org/)
- local file-based database setup using [Prisma](https://www.prisma.io/) and [better-sqlite3](https://www.npmjs.com/package/better-sqlite3)
- authentication powered by [jsonwebtoken](https://www.npmjs.com/package/jsonwebtoken)
- logging to both console and files
- basic styling using [Tailwind CSS](https://tailwindcss.com/)
- prebuilt components using [Shadcn UI](https://ui.shadcn.com/)
- pre-hidden config files using [Hide files for VSCode](https://marketplace.visualstudio.com/items?itemName=roonie007.hide-files)
